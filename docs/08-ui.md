# 08 · UI

The look is **realistic hardware**: photoreal panel, 3D-rendered knobs and buttons, drawn with pre-rendered images. The **P5X Panel** design canvas is the reference for **layout only** (section order, which controls exist, positions, the MIDI Learn / Debug / Settings screens), not for the look. Materials, lighting and asset specs come from `13-art-pipeline.md` and the chosen concept render `../artwork/concepts/direction-3.jpg` (Direction C, kept outside the code repo). Ask before deviating from either. Milestones 1–4 use a placeholder editor (below); the real panel is milestone 5.

## Placeholder editor (milestones 1–4)
- A plain grid of `Slider`s and `ToggleButton`s, one per parameter in 01-parameters.md, grouped by section headings, generated from the parameter layout.
- Must support right-click MIDI Learn exactly as specified in 07-midi.md.
- Top strip: Debug toggle, settings button, MIDI activity LED, CPU %, learn status text.
- No styling effort. It gets deleted in milestone 5.

## Tech
- **Plain JUCE components drawing pre-rendered images.** No WebView.
  - Panel background (including the wood cheeks and printed section labels) = one image per scale.
  - Knobs = filmstrip images (one tall PNG, N frames of rotation); the component draws the frame for the current value.
  - Buttons = four-state images (off, on, off-pressed, on-pressed). The whole cap is backlit, so the glow is baked into the image (13-art-pipeline.md, `art/style.json`).
  - **Drawn in code on top of the images:** preset display text, CPU %, learn ring, value tooltips, the on-screen keyboard's held-key tint, focus outlines. These stay vector so they're crisp and dynamic.
- Assets come in **@1x and @2x**. Pick the set by `scale × display scale factor`: use @2x when the effective scale is > 1.0, else @1x. Draw with high-quality resampling (`Graphics::highResamplingQuality`).
- Base size 1440 × 600. Resizable 75 %–150 % with fixed aspect ratio, via `setResizeLimits` + `getConstrainer()->setFixedAspectRatio`. All layout in base coordinates, scaled with an `AffineTransform`.
- Assets are loaded once at editor construction from BinaryData into `juce::Image` (cached via `ImageCache`). Never decode images in `paint()`.
- Font: **Kode Mono** (Google Fonts, SIL OFL 1.1, designer Isa Ozler), the only typeface in P5X. Files in `Resources/fonts/KodeMono/`: static Regular/Medium/SemiBold/Bold instances (made from the variable font with fontTools; embed these via BinaryData) plus the original variable font and `OFL.txt` (ship the license with the plugin). Listed in THIRD_PARTY.md. Uppercase, slightly letter-spaced, for everything on the panel: printed labels baked into the art and code-drawn overlays (tooltips, learn status, preset name), so they match. The Debug console and Settings dialog use it too.
- Repaint on a 30 Hz timer only for things that change (meters, LEDs, learn ring). Knobs repaint via attachment callbacks.
- UI never reads DSP objects; it uses APVTS attachments and telemetry snapshots.

## Components
- **Knob:** filmstrip image (see 13-art-pipeline.md for size and frame count), 270° sweep (−135° to +135°); frame index = `round(normalizedValue × (frames − 1))`. The label is printed on the panel image, not drawn in code. Vertical drag (200 px = full range), Shift = fine (×0.1), double-click = reset to default, mouse wheel = 1 % per notch. Hover tooltip: `Name · value · CC n` (CC part only if mapped). Stepped params (`osc_*_freq`) snap to steps and show `+7 st`.
- **LED button:** four-state image (off, on, off-pressed, on-pressed) per 13-art-pipeline.md; the pressed states show while the mouse is down. Label printed on the panel image.
  - Independent toggles: oscillator waves, sync, Lo Freq, Kbd, Poly-Mod and Wheel-Mod destinations, Unison, Velocity, Aftertouch.
  - Radio group: LFO shape (exactly one lit).
  - `flt_kbd`: the two buttons Kbd ½ and Kbd Full act as a radio group that allows none: clicking the lit one turns it off (Off).
  - `perf_voices`: a button showing `Voices 5`; click cycles 5 → 8 → 10.
- **Sections:** part of the panel image (printed borders and titles). Performance's `+ Extras` marking is printed too.
- **Preset display:** 3-digit 7-segment readout drawn in code (segment shapes, not a font) in the display window printed on the panel: lit segments `#FF8A1F` with a soft glow, unlit segments faintly visible. Shows the preset number only. The preset name and edited state are shown per OPEN_QUESTIONS #13 (placeholder: a small light-grey Kode Mono line under the display, with `*` when edited). Prev/next buttons; Save opens a name prompt.
- **Learn state:** waiting control gets a 2 px accent ring 6 px outside the knob, pulsing opacity 1.0 ↔ 0.35 at 1 Hz. Top bar replaces the subtitle with the learn status text.
- **MIDI LED:** flashes for 80 ms on any incoming MIDI (after channel filter).
- **On-screen keyboard:** 61 keys, C2–C7 (MIDI 36–96, the whole playable range; see 07-midi.md), so it never shifts (Z/X move only the computer keyboard). Held notes tinted accent; pitch and mod wheels at left are draggable and spring back (pitch only).

## Layout
- **Top bar (60 px):** P5X wordmark · subtitle ("Programmable Polyphonic Synthesizer") · preset prev / display / next · Save · MIDI LED · CPU % · Debug button · settings gear.
- **Row 1:** Poly-Mod (Filt Env, Osc B; Freq A / PW A / Filter) · LFO (Frequency; Saw / Tri / Square) · Wheel-Mod (LFO·Noise; Freq A / Freq B / PW A / PW B / Filter) · Oscillator A (Frequency, Pulse Width; Saw / Pulse / Sync) · Oscillator B (Frequency, Fine, Pulse Width; Saw / Tri / Pulse / Lo Freq / Kbd).
- **Row 2:** Mixer (Osc A, Osc B, Noise) · Filter (Cutoff, Resonance, Env Amt; Kbd ½ / Kbd Full) · Filter Envelope (A D S R) · Amplifier Envelope (A D S R) · Performance + Extras (Glide, Vintage; Unison, Voices, Velocity, Aftertouch) · Master (Tune, Volume).
- **Bottom strip:** wheels + keyboard.
- 28 px light oak cheeks both sides (Direction C).
- The settings dialog follows the Audio/MIDI settings artboard. The artboards (Main panel, Audio/MIDI settings, Debug console) aren't in the repo yet (OPEN_QUESTIONS #14, #15). Until they are, the Settings dialog and Debug console use a plain functional layout in this palette and Kode Mono. Items listed in 10-debug-and-harness.md that the artboard doesn't draw (program change, pitch bend range, HQ mode) go at the end of the MIDI section in the same label + select row style.
- Controls with no panel home: `bend_range` (settings dialog), `hq_mode`, `midi_channel`, `takeover_mode`, `program_change_enabled` (settings dialog).

## Accessibility and polish
- Every control has a JUCE accessible title (param name) and value.
- Keyboard focus: Tab moves between controls, arrow keys adjust by 1 %, Enter toggles buttons.
- Text contrast: labels ≥ 4.5:1 on their background (the palette meets this; don't darken labels).

## Tests / acceptance
- Screenshot at 100 % matches the Main panel artboard layout (section order, control counts, labels) and the chosen concept's look, on manual review by the user.
- Knob frames line up with the printed scale at 0 %, 50 % and 100 % (no visible offset).
- At 75 %, 100 %, 150 % and on a 200 % Windows display, nothing looks blurry or pixelated.
- Every parameter in 01-parameters.md (except `bend_range`) has exactly one panel control; a unit test walks the component tree and compares against the parameter list. (Choice params drawn as button groups: OPEN_QUESTIONS #32.)
- Resizing 75 %→150 % keeps aspect ratio and doesn't clip any control.
